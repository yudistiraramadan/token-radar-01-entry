Methodology

Implied value = size × growth × maturity: what this protocol's token would be worth if it launched with today's record. Every number derives from the snapshot's own TVL, 7-day change and listing age — no hardcoded protocol names. Click any row for its breakdown and farm plan.

• Size fits an overall log-log curve on the — protocols whose token already trades (gecko_id, symbol and mcap recorded): mcap = — × tvl— (R²=—). Per-category multipliers are the median mcap/curve ratio, shrunk toward 1.0 by sample weight n/(n+5), for categories with 3+ comparables: —. Output clipped to [—×TVL, —×TVL], the empirical p10–p90 band.

• Growth: clip(1 + 2·change_7d/100, 0.5, 2.0) — amplifies 7-day TVL momentum, capped to prevent outliers. No reported change ×1.0.

• Maturity: step function by days since DefiLlama listed_at. Young (<90d) ×0.6, proving (<1y) ×0.9, sweet spot (1–2y) ×1.1, mature (2–4y) ×1.0, stale (>4y) ×0.85. Null listed_at ×0.95.

• Live vs pre-token: protocols whose token already trades price the curve and are never ranked. The board holds all — watchlist protocols (★, TVL ≥ —, no token recorded) plus the top — of — other pre-token protocols that pass the watchlist's own cleanliness rule (no CEX, Bridge, Liquid Staking, wrapped, staked or versioned names), ranked descending by implied value.

• Farm plan: five steps per protocol — three for its category (venue, deposit size by TVL tier, costs and lock times), then a 60-day hold and a −15% 7-day TVL exit rule.
